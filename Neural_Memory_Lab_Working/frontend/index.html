MEMORY DEEP DIVE

Know what is measured.

Memory is a system-level picture, not just a model file size.

01

Model weights

Parameters stored in the model. Estimate from parameter count and representation precision; compare with actual serialized file size.

MEASURE + CALCULATE
02

Activations

Intermediate tensors produced during inference. Depend on architecture, input shape, and batch size.

WORKLOAD-DEPENDENT
03

Gradients

Training-related tensors. Usually not allocated during ordinary inference-only evaluation.

TRAINING ONLY
04

Optimizer states

Extra training state maintained by optimizers such as Adam. Not part of a normal inference-only run.

TRAINING ONLY
05

Runtime overhead

Python, libraries, allocator behavior, shared memory, and other process allocations affect observed RSS.

OBSERVED / APPROXIMATE
i
Interpret measurements carefully

Process RSS sampling is an approximation and does not equal exact tensor allocation. All results must identify the measurement method and its limitations.
